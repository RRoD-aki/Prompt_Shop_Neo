# Prompt Shop Neo README

Prompt Shop Neoは、Stable Diffusion WebUI / Forge系UIのプロンプト入力を補助するためのカード型プロンプト管理ツールです。  
よく使うタグや複合プロンプトをカードとして登録し、クリックでプロンプト欄へ追加・削除できます。  
また、現在のプロンプト欄をタグチップとして表示し、ドラッグ＆ドロップで並び替えや強調調整ができます。

---

## 主な機能

- カードクリックによるプロンプト追加・削除
- 現在のプロンプト欄に応じたカード発光表示
- タグチップのドラッグ＆ドロップ並び替え
- タグチップの複数選択・一括移動・一括強調
- 強調値、括弧、一時除去、削除、改行チップの操作
- LoRAタグ `<lora:...>` の専用処理
- カードの追加・編集・削除
- カテゴリ管理
- カード画像の追加・削除
- WebUIの現在の生成画像からカード作成
- PNGメタデータによるカードのインポート・エクスポート
- JSON書き出し
- 画像なしモード
- カードサイズ変更
- 検索

---

## 起動方法

WebUIを起動すると、画面右下に **「△ Prompt Shop」** タブが表示されます。

タブをクリックするとPrompt Shopが開きます。  
開いた状態では表示が **「▽ Prompt Shop」** に変わります。  
もう一度クリックすると閉じます。

Prompt Shopの上端にある細いバーを上下にドラッグすると、表示エリアの高さを変更できます。

高さは保存されますが、開閉状態は保存されません。  
WebUI起動時や再読み込み時は、必ず閉じた状態から始まります。

## 基本操作

### カードを使う

カードをクリックすると、そのカードのプロンプトがWebUIのプロンプト欄に追加されます。

すでに同じプロンプトが入っている場合は、同じカードをもう一度クリックすると削除されます。  
単純な文字列一致ではなく、強調表記や複合タグの中身も見て判定します。

例：

```txt
(1girl:1.3)
```

この状態で `1girl` のカードをクリックすると、`1girl` 相当のタグとして扱われます。

### カードのツールチップ

カード下部のテキスト部分にマウスを乗せると、カード名とプロンプト全文が表示されます。

### カードの発光色

| 色 | 意味 |
|---|---|
| 緑 | カード内のすべてのプロンプトが現在のプロンプト欄に入っている |
| 水色 | 複合カード内の一部だけが現在のプロンプト欄に入っている |

---

## タグチップ欄

Prompt Shop上部には、現在のプロンプト欄の内容がタグチップとして表示されます。

タグチップはドラッグ＆ドロップで並び替えできます。  
並び替えた結果は、WebUI側のプロンプト欄にも反映されます。

### タグチップの色

| 色 | 意味 |
|---|---|
| 緑 | 単独カードとして登録されているタグ |
| 水色 | 複合カードの一部として登録されているタグ |
| 薄紫 | LoRAタグ `<lora:...>` |
| 赤 | 一時除去中のタグ |
| 黄色枠 | 複数選択中のタグ |

### タグチップの操作ツール

タグチップにマウスを乗せると操作ツールが表示されます。

| 操作 | 内容 |
|---|---|
| 強調＋ | 強調値を0.1上げる |
| 強調－ | 強調値を0.1下げる |
| 括弧＋ | 括弧を1段増やす |
| 括弧－ | 括弧を1段減らす |
| 改行 | そのタグの前に改行チップを追加する |
| 一時除去 | プロンプトから一時的に外す |
| 復帰 | 一時除去したタグを戻す |
| 削除 | タグチップを完全に削除する |

### 強調の例

```txt
1girl
```

強調＋を押すと以下のようになります。

```txt
(1girl:1.1)
```

さらに強調＋を押すと以下のようになります。

```txt
(1girl:1.2)
```

強調値が `1.0` に戻った場合は、基本的に通常タグへ戻ります。

```txt
(1girl:1.0)
```

ではなく、

```txt
1girl
```

になります。

### 括弧の例

```txt
1girl
```

括弧＋を押すと以下のようになります。

```txt
(1girl)
```

さらに括弧＋を押すと以下のようになります。

```txt
((1girl))
```

### 一時除去

一時除去を押すと、そのタグはプロンプト欄から外れますが、タグチップ欄には赤色で残ります。  
復帰を押すと、元のプロンプトへ戻ります。

一時的に比較したいタグを外すときに使います。

### 改行チップ

改行ボタンを押すと、そのタグの前に改行チップが入ります。  
改行チップも通常のタグチップと同じように移動・削除できます。

---

## 複数選択

タグチップ欄の空白部分をドラッグすると、範囲内のタグチップを複数選択できます。

複数選択した状態でタグをドラッグすると、選択したタグをまとめて移動できます。

複数選択した状態で強調や括弧を操作すると、タグをまとめて処理します。

例：

```txt
1girl, blue hair
```

この2つを選択して強調＋を押すと、以下のようなまとまりになります。

```txt
(1girl, blue hair:1.1)
```

---

## LoRAタグの扱い

`<lora:name:1>` のように `<>` で囲まれたタグは、カンマが無くても1つのタグチップとして扱われます。

例：

```txt
1girl<lora:test_lora:1>smile
```

この場合、`<lora:test_lora:1>` は単独のLoRAタグチップになります。

LoRAタグは薄紫色で表示されます。  
カードとして登録されていても、LoRA専用色が優先されます。

LoRAタグに強調操作をした場合、通常タグのように `(<lora:...>:1.1)` にはなりません。  
以下のようにLoRAタグ内部の数値を変更します。

```txt
<lora:test_lora:1.1>
```

また、`<>` 内の `_` は、単独 `_` のスペース置換対象外です。

## 下部ツールバー

Prompt Shop下部には操作用ツールバーがあります。

| ボタン / 設定 | 内容 |
|---|---|
| `,の後にスペースを挿入` | カンマの後ろを `, ` に整える |
| `単独の_をスペースに置換` | `blue_hair` を `blue hair` に変換する。`__` やLoRA内の `_` は維持 |
| `画像なしモード` | カード画像を表示せず、テキスト中心の軽量表示にする |
| `カテゴリ管理` | カテゴリを追加・削除・編集する |
| `編集モード ON` | カード編集・削除・移動を有効にする |
| `＋カード追加` | 手動でカードを追加する |
| `＋カードインポート` | PNGメタデータからカードを取り込む |
| `生成画像をカード化` | WebUIの現在の生成画像からカードを作成する |
| `JSON書き出し` | 現在のカードデータを `prompts.json` として書き出す |
| `サイズ` | カードサイズを変更する |
| 検索欄 | カード名・プロンプト内容で検索する |

## 編集モード

**編集モード ON** を押すと編集モードになります。  
編集中はツールバーが赤くなり、カードに編集用ボタンが表示されます。

編集モード中にできることは以下です。

| 操作 | 内容 |
|---|---|
| カードドラッグ | カードの並び替え |
| カードをカテゴリバーへドロップ | そのカテゴリへ移動 |
| カードをカード一覧内のカテゴリ欄へドロップ | そのカテゴリへ移動 |
| `✎` | カード編集 |
| `×` | カード削除 |
| `🖼️×` | カード画像だけ削除 |
| `PNG` | カードをPNGとして書き出し |

編集モードを終了するには、下部ツールバーの **編集中：クリックで終了** を押します。

---

## カード追加

下部ツールバーの **＋カード追加** からカードを追加できます。

入力項目：

- タイトル
- プロンプト
- 画像
- カテゴリ

画像はドラッグ＆ドロップで追加できます。  
PNG画像にPrompt Shop用メタデータが入っている場合は、タイトルとプロンプトも読み込まれます。

WebUIに生成画像が表示されている場合は、**現在の生成画像を使用** でカード画像にできます。

---

## カード編集

編集モード中にカードの `✎` ボタンを押すと、カード編集画面が開きます。

編集できる項目：

- タイトル
- プロンプト
- 画像
- カテゴリ

画像の差し替えや、現在の生成画像の使用もできます。

変更がある状態でキャンセル、またはモーダル外をクリックすると、破棄確認が出ます。

---

## カテゴリ管理

下部ツールバーの **カテゴリ管理** からカテゴリを編集できます。

できること：

- 親カテゴリの追加
- 子カテゴリの追加
- カテゴリ名の変更
- カテゴリアイコンの変更
- カテゴリ削除

カテゴリ管理画面を開いている間は、背後のPrompt Shop操作はできません。

---

## PNGインポート・エクスポート

### PNGエクスポート

編集モード中にカードの **PNG** ボタンを押すと、カード画像をPNGとして書き出します。

書き出したPNGには、カード名とプロンプトがメタデータとして埋め込まれます。

使用される主なメタデータキー：

- `Title`
- `Prompt`
- `Description`
- `promptshop_title`
- `promptshop_prompt`

### PNGインポート

下部ツールバーの **PNG取込** から、PNGをカードとして取り込めます。

PNG内にPrompt Shop用メタデータがある場合は、タイトルとプロンプトを読み込みます。  
メタデータが無い場合は、ファイル名などを元にカードが作成されます。

取り込んだカードは **未分類** に追加されます。

複数PNGの一括取り込みにも対応しています。

---

## JSON書き出し

下部ツールバーの **JSON書き出し** を押すと、現在のカードデータを `prompts.json` として書き出します。

カードデータは以下のような形式です。

```json
{
  "settings": {
    "siteTitle": "PROMPT SHOP NEO",
    "siteLogo": "PROMPT SHOP NEO",
    "categories": []
  },
  "prompts": [
    {
      "id": "カードID",
      "title": "カード名",
      "prompt": "プロンプト",
      "image": "assets/no-image.png",
      "category": "カテゴリID"
    }
  ]
}
```

---

## 画像なしモード

**画像なしモード** をONにすると、カード画像を表示せず、タイトルとプロンプトだけの軽量表示になります。

カード数が多い場合や、画像が不要なタグ管理に向いています。

---

## 検索

下部ツールバー右側の検索欄から、カードを検索できます。

検索対象：

- カード名
- プロンプト本文

---

## データ保存について

カードやカテゴリの変更は、拡張側の保存APIを通して `assets/prompts.json` に保存されます。

念のため、大きな編集前には **JSON書き出し** でバックアップを取ることをおすすめします。

## 配置例

拡張フォルダの配置例です。

```txt
extensions/
└─ Prompt_shop_neo/
   ├─ prompt_shop.py
   ├─ javascript/
   │  └─ inject.js
   └─ assets/
      ├─ index.html
      ├─ main.js
      ├─ style.css
      ├─ prompts.json
      └─ no-image.png
```

フォルダ名を変更した場合は、`inject.js` 内のiframe読み込み先パスも合わせて変更してください。

例：

```js
/file=extensions/Prompt_shop_neo/assets/index.html
```

## テスト時に確認してほしいこと

テスターに確認してもらいたい項目です。

- Prompt Shopの開閉ができるか
- 高さ調整ができるか
- カードクリックでプロンプト追加・削除ができるか
- 同じカードを連打してもタグが重複しないか
- プロンプト欄を直接編集したとき、カード発光が追従するか
- タグチップ欄が現在のプロンプト欄に追従するか
- タグチップをドラッグで並び替えできるか
- 複数選択と一括移動ができるか
- 強調＋ / 強調－ が正しく動くか
- 括弧＋ / 括弧－ が正しく動くか
- 改行チップを追加・移動・削除できるか
- 一時除去と復帰が正しく動くか
- LoRAタグ `<lora:...>` が1つのタグチップとして扱われるか
- LoRAタグの強調値が `<lora:name:1.1>` 形式で変化するか
- 編集モードでカード編集・削除・画像削除ができるか
- 編集モードでカードをカテゴリへ移動できるか
- タグチップをカード一覧へドロップしてカード作成できるか
- PNG書き出しができるか
- PNG取込でカードを復元できるか
- PNG取込カードが未分類に入るか
- JSON書き出しができるか
- 画像なしモードで表示崩れしないか
- カードサイズ変更で3:4比率が崩れないか
- モーダル表示中に背後のボタンを押せないか
- 変更がある状態でキャンセルしたとき、破棄確認が出るか

## 注意事項

- 大量のカード編集前には、`JSON書き出し` でバックアップを取ってください。
- PNGインポートはPNGファイルのみ対象です。
- LoRA名に含まれる `_` は、単独 `_` のスペース変換対象外です。
- 編集モード中はカードをドラッグできるため、通常操作時は編集モードをOFFにしておくと誤操作を防げます。
